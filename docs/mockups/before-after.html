3 · Run pipeline & run model BEFE Phase 2

Before

queued→pulling (full clone)→restoring_cache→installing→execute (+ results, cleanup, release — invisible)
failureKind: test | infra | precondition
no hub claim stamp   # two hubs on one DB can both run it
no app preflight    # runs against whatever is installed
late writer can overwrite a pass

After

queued→claimed (hub id, atomic)→pulling (bare repo + worktree)→restoring_cache→installing→app preflight→executing→collecting→releasing
errorClass: device_offline | install_failed | test_assertion |
            network_timeout | appium_session | build_missing |
            cancelled | unknown
status:     queued … completed | failed | cancelled | partial
executor:   { kind: 'hub', machineId }   # → 'agent' later
claimedBy:  hub machineId; terminal writes guarded
